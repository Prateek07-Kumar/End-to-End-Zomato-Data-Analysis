**Zomato Restaurant Data Analysis**

This project explores restaurant data from Zomato to uncover trends in ratings, pricing, online ordering, and table booking preferences. The dataset contains 148 records and 
7 features about restaurants, including their ratings, cost, and type.

### Objectives
- Analyze restaurant ratings and voting patterns.
- Study the relationship between online orders, table booking, and ratings.
- Compare price ranges for different restaurant categories.
- Identify trends in popular restaurant types.

### Dataset Overview
- Rows: 148
- Columns: 7
- Key Columns:

### Key Columns:
  - name – Restaurant name.
  - online_order – Whether the restaurant accepts online orders.
  - book_table – Whether table booking is available.
  - rate – Average customer rating.
  - votes – Number of customer votes.
  - approx_cost(for two people) – Estimated cost for two.
  - listed_in(type) – Category/type of restaurant.
